Binary Search — The Hidden Art of Dividing and Conquering

From classic confusion (< vs <=) to a single invariant template that solves every binary search problem.

🌅 A Story Every Coder Knows

You write your first Binary Search in college. It works once, fails on the next case, and suddenly the humble symbols < and <= feel like final bosses.

“Why does changing one comparison fix a test and break three others?”

Here’s the truth: Binary Search isn’t about the middle; it’s about boundaries. Once you think in boundaries, you never memorize edge cases again—you prove them.

⚙️ The Classic Way (The One Everyone Starts With)

def binary_search(nums, target):
    l, r = 0, len(nums) - 1
    while l <= r:
        mid = (l + r) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            l = mid + 1
        else:
            r = mid - 1
    return -1

Beautiful—until you’re asked: “Find the first element ≥ x.” Suddenly the cousins < and <= start a family feud.

💡 The Real Secret: The Invariant

We maintain two zones and never break them:

🟥 Left zone — always False (invalid)
🟩 Right zone — always True (valid)

We shrink the gap until they touch. The first index in the True zone is the answer.

def binary_search_invariant(predicate, lo, hi):
    l, r = lo - 1, hi + 1      # l = False, r = True
    while r > l + 1:
        mid = (l + r) // 2
        if predicate(mid):
            r = mid            # mid is True → pull right in
        else:
            l = mid            # mid is False → push left out
    return r                    # first True

Every binary search problem is just this loop with a different predicate(mid).

🔮 Enlightenment Through Examples

🍌 875. Koko Eating Bananas (min valid speed)

Question in English: If Koko eats at speed k, can she finish in ≤ h hours? Find the first speed where the answer is True.

import math

class Solution:
    def minEatingSpeed(self, piles, h):
        left, right = 0, max(piles) + 1
        while right > left + 1:
            mid = (left + right) // 2
            hours = 0
            for p in piles:
                hours += math.ceil(p / mid)
            if hours <= h:
                right = mid     # valid (True)
            else:
                left = mid      # invalid (False)
        return right

🎯 34. Find First and Last Position of Element

Two boundaries: first index ≥ target and first index > target (then subtract 1).

class Solution:
    def searchRange(self, nums, target):
        n = len(nums)
        if n == 0:
            return [-1, -1]

        # First index >= target
        left, right = -1, n
        while right > left + 1:
            mid = (left + right) // 2
            if nums[mid] >= target:
                right = mid
            else:
                left = mid
        first = right
        if first == n or nums[first] != target:
            return [-1, -1]

        # First index > target → last = right - 1
        left, right = -1, n
        while right > left + 1:
            mid = (left + right) // 2
            if nums[mid] > target:
                right = mid
            else:
                left = mid
        last = right - 1
        return [first, last]

🏔️ 162. Find Peak Element

True zone starts when slope turns down: nums[mid] > nums[mid+1].

class Solution:
    def findPeakElement(self, nums):
        left, right = -1, len(nums) - 1
        while right > left + 1:
            mid = (left + right) // 2
            if nums[mid] > nums[mid + 1]:
                right = mid     # in (or beyond) the peak
            else:
                left = mid      # still climbing
        return right

🔁 33. Search in Rotated Sorted Array

Rotation breaks monotonic predicate, but we still delete half confidently by choosing the sorted side.

class Solution:
    def search(self, nums, target):
        l, r = 0, len(nums) - 1
        while l <= r:
            mid = (l + r) // 2
            if nums[mid] == target:
                return mid
            if nums[l] <= nums[mid]:           # left half sorted
                if nums[l] <= target < nums[mid]:
                    r = mid - 1
                else:
                    l = mid + 1
            else:                               # right half sorted
                if nums[mid] < target <= nums[r]:
                    l = mid + 1
                else:
                    r = mid - 1
        return -1

🚢 1011. Capacity to Ship Packages Within D Days

Predicate: with capacity C, can we ship within D days? Find first True.

class Solution:
    def shipWithinDays(self, weights, days):
        left, right = 0, sum(weights) + 1
        while right > left + 1:
            mid = (left + right) // 2
            day_count, curr = 1, 0
            for w in weights:
                if curr + w > mid:
                    day_count += 1
                    curr = 0
                curr += w
            if day_count <= days:
                right = mid     # valid capacity
            else:
                left = mid      # too small
        return right

📚 410. Split Array Largest Sum

Same structure as shipping: smallest possible “largest subarray sum” with ≤ k groups.

class Solution:
    def splitArray(self, nums, k):
        left, right = 0, sum(nums) + 1
        while right > left + 1:
            mid = (left + right) // 2
            groups, curr = 1, 0
            for x in nums:
                if curr + x > mid:
                    groups += 1
                    curr = 0
                curr += x
            if groups <= k:
                right = mid     # valid bound
            else:
                left = mid      # too tight
        return right
